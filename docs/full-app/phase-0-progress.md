  - Deviation, fake page: `innerHTML` and `textContent` are two views of one value, as in a browser, where 08 describes plain properties. `innerText` puts a line break at block boundaries, including the hero's `span.cond`, which `src/styles/app.css` makes a block. 08's "tags stripped" version would have shared "Valley fog likely.Wind 2 mph", which the real page never does. `matchMedia` reads `min-width` queries instead of returning one constant. The capture records only elements a render function wrote to (`written`), not every one it looked up, so a later step that reads one more element does not break the files.
  - Deviation, extra keys: beyond 08's table the capture records `later` (the model and the home screen at the clock plus 90 minutes on the same data, which covers fog on the river in daylight and the stale current conditions), more of `text` (fog per hour, confidence text, precipitation notes, kinds, rates, AQI and UV words, alert levels, light by hour, sun times per day, flow), each view's `summary`, the Week view under two other Plan a row choices, and more failure states (`status.header`, a forecast failure alone, a partial failure). `app.updated` is set to the fetch time so the header reads "Updated".

  - Deviation, october-fog at 06:00: first light that day is 6:34 AM, so it is still dark. The case shows the next period and hides On the water now, as the app does. Fog now, in daylight, is covered by `later`.
  - Deviation, names and tools: cases are named `<scenario>-<hhmm>-<default|custom>` and `june-calm-1200-wide`. `test/golden.test.js` adds a test that fails in write mode, and the seven condition tests. `GOLDEN_FORCE=1` and `scripts/golden.mjs write --force` exist for P0.1 only. The JSON is pretty printed three levels deep, so one hour or one day is one line.
  - Open: no clock falls on 2026-11-01 itself; the `fall-back` clocks are on 2026-10-31.
